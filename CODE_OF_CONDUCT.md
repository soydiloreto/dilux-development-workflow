# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] in full. It is
the standard most of the ecosystem already runs on, and adopting it by reference
rather than pasting a copy means it cannot quietly drift from the original.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## The short version

Be someone others can disagree with. Most of what happens in this repository is
argument — about whether a gate earns its cost, whether a check measures what it
claims, whether a decision in `docs/RATIONALE.md` went the wrong way. That is the
point, and it only works while the argument stays about the work.

Concretely: harassment, insults, and personal or political attacks are not
tolerated. Neither is publishing someone's private information. Disagreeing
sharply with an idea is fine and welcome; disagreeing with a person is not the
same thing.

## Reporting

Email **pablodiloreto@gmail.com**. Reports are handled privately, and you will
get an answer.

If the person you need to report is me, say so plainly in the message — a code of
conduct whose only route runs through the maintainer is worth exactly nothing if
the maintainer is the problem, and I would rather hear it than have you leave
without saying anything.
